SOLMARA — Streets of the Sun: a 2D canvas open-world crime game. Drive and walk across six districts of the island city of Solmara, take on 8 story jobs with crew-and-tools planning, outrun the Solmara Police Department as it escalates from patrols to roadblocks, PIT units and the HAWK ONE helicopter, and build respect, turf standing and a garage full of upgraded cars.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Or build the entry dossier with `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
